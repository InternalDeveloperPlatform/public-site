# Easypanel

**Claim:** Deploy anything on your server.

**Focus:** Self-hosted application and database deployment through a web interface.

**Website:** [easypanel.io](https://easypanel.io/)

**Docs:** [easypanel.io/docs](https://easypanel.io/docs)

## What is Easypanel?

Easypanel is a proprietary deployment panel for developers, small teams and self-hosters who want to run applications and databases on their own server. It provides a web interface for deploying from Git repositories or Docker images, configuring environment variables, connecting domains and managing SSL certificates. Templates help deploy common applications without configuring every service from scratch.

Unlike a hosted PaaS, Easypanel runs on infrastructure supplied by the user. Server hosting costs are separate from the software plan. Its free plan supports up to three projects, with unlimited services and deployments; paid plans are also available. See the [current pricing](https://easypanel.io/pricing) for plan details.
